- 添付HTMLを元に32枚の埋め込み画像をファイルに分離し、元の参照を更新。
- 既存News & Topics 6件を編集可能なJSONデータへ移行。
- 日本語のDecap CMS管理画面を追加。写真選択、本文、リンク、掲載／非掲載、表示順に対応。

## 確認済み

- Node.jsの自動テスト7件：記事のHTMLエスケープ、不正リンク拒否、非掲載／表示順、画像パスと日付検証、OAuth改ざん拒否、期限／state不一致拒否、Write権限確認、ポップアップ送信先制限。
- ブラウザーで日本語の管理画面へローカルログインし、既存6件を表示。
- 管理画面からテスト記事を追加し、タイトル・本文・日付・写真を保存。
- ローカルHPと詳細ページに保存した文章・写真が表示されること。
- 掲載スイッチをオフにして保存すると、詳細ページが404となること。
- 日本語の全角句読点を含む記事ファイル名で動作すること。
- 管理画面の幅が900px未満の場合はプレビューを外し、入力欄を1列で表示する調整を追加。
- ソースHTML内の画像参照32件に欠損がないこと。
- Cloudflare公式Wrangler 4.152.0でPages Functionsのコンパイルに成功。
- 保存済みテスト記事のタイトルを修正し、ローカルHPへ自動反映されること。
- テスト記事・テスト写真は配布用データから削除済み。
- GitHub公開リポジトリの現在の `main` と `CNAME` を確認。
