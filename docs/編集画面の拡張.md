# HP全体の編集（確認用サイト）

管理画面：https://worldfut-hp.pages.dev/admin/
HP：https://worldfut-hp.pages.dev/

現在は確認用サイトの編集です。保存しても本番 worldfut.jp は変わりません。

## 編集する場所

- **HP全体・新規セクション → 全体設定・文字・セクション追加**：HP名、検索結果の説明文、オープニング、全体の文字設定、既存セクションの順序、新しいセクション。
- **既存HPの各項目**：トップ、団体概要・理念、活動内容・沿革・実績、お知らせ欄の見出し、募集案内、連絡先・お問い合わせ、上部メニュー、フッター。
- **お知らせ・掲載記事**：従来どおり、個々の記事・写真・掲載日の編集。

活動カード、沿革、クラウドファンディング、募集案内、メニュー・フッターのリンクは、一覧内で追加・削除・並べ替えができます。スライド写真は最低1枚を残してください。

## 文字の大きさ・フォント

「HP全体の文字設定」、または各ページの「文字の見た目」を開きます。

- フォント：ゴシック体・明朝体・丸ゴシック体。
- 見出しと本文の大きさ：小・標準・大。
- 文字の配置：左寄せ・中央寄せ。
- 見出しの太さ：標準・太字。
- 見出し・本文の文字色：色の選択、または # と6桁の色コード。

「全体設定に合わせる」または色の空欄は、個別設定を上書きしません。全体設定もその選択なら元のデザインを維持します。個別設定が優先されます。丸ゴシックなどの実際の書体は閲覧端末により異なり、未搭載の場合は代替フォントで表示されます。スマートフォンでの読みやすさ、特に背景と文字色の組み合わせを確認してください。

## 新しいセクションを追加

1. 「HP全体・新規セクション」から全体設定を開く。
2. 「新規セクション」の Add を押す。
3. 見出しと挿入位置を選ぶ。
4. 「文章・写真・ボタン」または「カード一覧」を選ぶ。
5. 普通の文章や写真、必要ならリンクを入力。
6. 「HPに表示する」をオンにする。
7. 上部の「公開」→「公開する」を押す。
8. 自動公開が完了するまで通常1〜数分待ち、HPを開いて確認。

同じ挿入位置に追加したセクションは、一覧の上から順に表示されます。文章・写真型のときカード一覧は使用されず、カード一覧型のとき本文・写真・ボタン欄は使用されません。不要なセクションは掲載スイッチをオフにして保存できます。

既存セクションの順序は6項目を1つずつ残し、自由に並べ替えできます。トップも移動できます。重複・不足や無効なリンクなどがあると公開処理が失敗し、直前に正常公開されたHPが継続表示されます。

## リンクと写真

- リンクは https:// で始まるURL、mailto:メールアドレス、または #about などのページ内リンク。
- 既存のページ内リンク：#top / #about / #activities / #media / #join / #contact。
- フッターの活動タブ：cambodia はカンボジア、japan は日本、history は沿革。
- 画像は管理画面でアップロードしたJPEG・PNG・WebP・GIFを選択。既存写真も初期データから引き継ぎ済み。
- お問い合わせメールアドレスの変更は、HP上の表示・メールリンクの変更です。フォーム送信先や受信サービスの設定変更は制作担当者へ依頼してください。

この編集画面は決まった部品を編集・追加する仕組みです。自由な位置への配置、任意フォントのアップロード、HTML・JavaScriptや新しい機能の追加は制作担当者が行います。データと写真は公開GitHubリポジトリへ保存されるため、非掲載の内容にも機密情報を入れないでください。
